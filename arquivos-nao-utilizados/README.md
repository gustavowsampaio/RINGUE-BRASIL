# Arquivos não utilizados

Esta pasta preserva os exemplos antigos do Web Data Viz que não fazem parte do Ringue Brasil atual.

- `public/simulador.html`: simulador antigo.
- `dashboard/`: cards de aquários e páginas do mural de avisos.
- `src/routes/`, `src/controllers/` e `src/models/`: código de aquários, medidas, avisos e empresas.
- `public/assets/icon/`: ícones antigos.
- `DOCUMENTOS_DE_APOIO/`: tutoriais e exemplos do material original.
- `README-web-data-viz.md`: instruções originais do projeto base.

Os arquivos foram movidos mantendo suas subpastas para facilitar a consulta. Esta pasta não é publicada pelo Express e suas rotas não são carregadas pelo app.js.

As páginas antigas são referências de estudo. Não foram adaptadas para funcionar a partir deste novo endereço.

O código antigo de sensores continua comentado em `public/js/alerta.js` e no final de `dashboard/dashboard.html`.
